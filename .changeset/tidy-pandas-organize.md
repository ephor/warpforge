The project page is now organized into tabs, the same way a task workspace is. Backlog is where you land; Runtime sits next to it and finally gets the whole screen — services, port-forwards and terminals in one full-height panel, with Start/Stop everything right in its header and the live `http://localhost:…` addresses of anything running listed above it. Each project remembers the tab you left it on, so switching back picks up where you were instead of resetting. The project name, path, port range, backlog count and New work item stay pinned at the top, and the stack of collapsible cards that used to push everything below the fold is gone.
