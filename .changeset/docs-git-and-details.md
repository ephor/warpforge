Documentation now covers Warpforge's git surface and the details that make a task pleasant to work in. A new page walks through the branch tree — checkout, rebase onto a branch without checking it out, merge, pull with rebase or merge, and the collision check that stops you overwriting a remote branch by accident — along with native context menus, amend that prefills the message you are rewriting, and why every git operation runs in the task's own worktree. The editor's full language support is now described properly: go to definition across files, find references, rename, hover documentation, completions and one-click language-server install. Smaller touches are written down too, from a chat that stays pinned to the newest message to notifications you can approve without switching apps.
