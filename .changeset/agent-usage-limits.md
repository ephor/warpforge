See how much of each coding agent's quota is left before you run out mid-task. The task header now shows your session and weekly usage at a glance, and clicking it opens every agent you are signed into — Claude, Codex and OpenCode — with how much is left on each, when the limit resets, and what the work would have cost at API rates. When one login is spent you can see which of your others still has room and switch to it right there, without leaving the task. The same breakdown lives in Settings.
