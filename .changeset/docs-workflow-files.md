The documentation now explains how to write your own workflow. The two that ship with Warpforge were the only ones described anywhere, which made them look like the whole menu — in fact any YAML file you drop in your project's `.warpforge/workflows/` shows up in the New Task picker for everyone who checks out the repository. The new reference covers every key, which agent each stage falls back to, the placeholders a custom prompt can use, and a worked example that plans on one agent, implements on another, and reviews on two.
