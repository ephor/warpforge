Permission prompts now appear on the tool call they are about. The transcript used to alternate between a card asking whether to run something and a separate card showing the command itself, which turned a run of approvals into a wall of boxes. The prompt is part of the tool's row: allow and deny sit under the command, and once you answer, the row keeps the outcome where its status normally goes. Conversations recorded before this update keep the old two-card layout, since the link between prompt and command was not stored back then.
