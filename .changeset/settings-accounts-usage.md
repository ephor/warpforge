Each agent login in Settings now shows the quota it has left, right on the account. Accounts and rate limits used to be two separate lists naming the same logins, so every account was drawn twice and you scrolled between them to work out which one had room. Settings → Agents now has a single "Accounts & usage" list: name, email, plan, remaining session and weekly quota, and what the harness has cost at API rates — all on one line per login. Harnesses that report usage but have no login switching, such as OpenCode, appear there too, so you can check your budget without opening a task.
