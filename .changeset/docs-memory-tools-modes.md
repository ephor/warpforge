The documentation now covers everything agents can do inside Warpforge. A new agent-tools reference explains all 31 tools your agents can call — reading a service's logs, restarting it, filing a task, remembering a decision, dispatching a sub-agent — and which of them only a lead agent gets. A new guide helps you pick between one agent, a lead delegating to sub-agents, and a full review pipeline, with the tradeoffs of each spelled out. Cross-harness memory and its dreaming pass get a page of their own, as does working with tasks and a backlog fed from GitHub or Linear.
