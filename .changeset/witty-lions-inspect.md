Clicking a backlog item now opens its details in a panel beside the list instead of taking you somewhere else. It shows the full description, who it is assigned to, when it was created and last changed, and a link straight to the issue in GitHub or Linear. Priority is editable right there, and so is status for items you wrote yourself — issues that came from a tracker show the tracker's own status, since that is where it is decided. Start task and Open task are both one click from the panel, and closing it with Escape or a click outside puts you back exactly where you were in the list.
