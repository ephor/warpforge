Screenshots in an issue now show up in the work item panel instead of a stray line of HTML. Warpforge fetches them using the same GitHub or Linear access it already imported the issue with, so pictures attached to private repositories load too — the ones that stay blank everywhere outside the tracker itself. Click one to open it full size in your browser; if it cannot be fetched at all, you get a link rather than a broken image. Descriptions also read like a document now, with more generous line spacing and larger headings, and the created and updated times moved down beside Start task where they stay out of the way.
