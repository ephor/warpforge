The project page's Files and Runtime tabs now behave like the rest of the app. Files opens what you pick in a tab strip, exactly as a task's workspace does, so the file name is in the tab and its path is shown once instead of twice; several files can stay open at a time, and the panel drops the save button it could never use. Runtime lost the second row of buttons above its list: starting and stopping everything now lives in the list headings themselves, one for Services and one for Port Forwards, with start offered while anything is still down and stop while anything is still up. Both lists carry the same status dot and the same panel heading as Files and Changes, so nothing about a port-forward row looks like a different kind of thing anymore.
