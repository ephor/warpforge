The button that re-reads an agent's model list now says so. It used to be a bare circular-arrow icon whose only explanation was a three-line tooltip you had to hover to find; it reads "Reload models list" and turns into "Reloading…" while it works. Use it after adding a provider or model outside Warpforge, since the list is cached until then.
